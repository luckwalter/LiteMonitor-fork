=========================================================
         					LiteMonitor 使用说明
					     [ 开源 | 免费 | 安全 | 透明 ]
=========================================================

[1] 运行环境 (必读)
----------------------------------------------------------------
本软件基于微软最新的 .NET 8 框架开发。
如果双击软件无反应或报错，请确保安装了【.NET Desktop Runtime 8.0】环境。

* 下载地址 (微软官网):
  https://dotnet.microsoft.com/zh-cn/download/dotnet/thank-you/runtime-desktop-8.0.22-windows-x64-installer


[2] 权限与驱动说明
----------------------------------------------------------------

1. 管理员运行：
   请始终以【管理员身份】运行本程序。

2. 为了能够读取CPU温度/频率/功耗等数据，本软件需依赖PawnIO驱动
   * 软件启动时会自动检测是否安装PawnIO驱动，若未安装会自动提醒安装。
   * 如果自动安装失败，您可以手动下载 PawnIO 驱动进行安装。
   * 下载地址: https://gitee.com/Diorser/LiteMonitor/raw/master/resources/assets/PawnIO_setup.exe


[3] 关键文件与数据管理
----------------------------------------------------------------
为了方便备份或重置，以下是核心文件的用途：

* Settings.json (配置文件)
  保存了显示模式、监控项目、告警阈值等所有设置。
  > 故障解决：如果软件配置错乱无法启动，删除此文件可重置为默认状态。

* TrafficHistory.json (流量记录)
  记录了每日的上传/下载流量统计数据。
  > 隐私清理：如需重置历史流量统计，可直接删除此文件，软件会自动重建。

* LiteMonitor_Error.log（崩溃错误日志）
  软件运行崩溃或异常时的日志记录。

* resources/themes/*.json (主题文件)
  您可以直接编辑文本修改配色，或使用软件内置的【主题编辑器】进行可视化修改。

* resources/lang/*.json (语言包)
  支持多语言（中/英/日/韩等）。如需修正翻译或修改内容，可直接用记事本编辑对应文件。

* resources/plugins/*.json (插件文件)
  存放插件配置与扩展功能定义，可自由增删插件实现个性化监控。
  > 自定义插件：将符合规范的插件 JSON 放入此目录，重启软件即可生效；删除对应文件即可卸载插件。


[4] 关于本项目 (Open Source)
----------------------------------------------------------------
LiteMonitor 是一款代码完全开源的免费软件。
我们承诺代码公开透明，绝无任何恶意后门或隐私窃取行为。
因涉及底层硬件数据读取，部分杀毒软件可能会拦截此软件。
如果运行软件或者设置开机启动时出现拦截，请将软件目录添加至杀软信任/白名单。

[5] 本地定制版说明 (Local Custom Build)
----------------------------------------------------------------
本份程序基于上游 v1.3.6 源码在本地定制构建。
本节内容记录相对官方版本的改动，与上文冲突时以本节为准。

* 运行环境要求（重要：已变更）
  ------------------------------------------------------
  本版本已从 .NET 8 升级至 .NET 10，因此上文 [1] 节中要求安装的
  【.NET Desktop Runtime 8.0】不再适用，请改为安装：

      .NET Desktop Runtime 10.0 (LTS)

  下载地址: https://dotnet.microsoft.com/zh-cn/download/dotnet/10.0
  （务必选择 Windows Desktop Runtime，而非普通的 .NET Runtime；
    两者名称相似，只装后者仍会提示缺少运行环境，这是最常见的坑。）

  升级理由：官方所用的 .NET 8 将于 2026-11-10 终止支持，此后不再
  提供任何安全更新；.NET 10 为长期支持版本，支持至 2028-11-14。
  实测升级后源码零改动即可编译，依赖式单文件体积仅约 6 MB。

  >> 若本机已装有 .NET 10 桌面运行时（本机已具备 10.0.12），
     直接双击即可运行，无需安装任何东西。
  >> 若要拷贝到没装 .NET 的机器，请改用「自包含」方式发布，
     体积约 117 MB，不依赖目标机环境。

* 相对官方版的修复
  - 补回了从未被上游提交进仓库的《使用说明(必读).txt》(即本文件)。
    官方 csproj 一直在引用它，但仓库里根本没有 —— 任何人 clone 下来
    直接编译都会被 MSB3030 中断。纳入仓库后，本说明也会随每次打包
    自动输出到发布目录。
  - 新增 .gitignore，避免 bin/ obj/ 等构建产物被误提交。
  - 补齐 resources 下的 LiteMonitorFPS.exe 与 LiteMonitor.Updater.exe：
    单文件发布模式不会把这两个 exe 落到磁盘，若不补上，
    FPS 帧数统计与「检查更新」功能会失效。

* 已知设计行为（非故障）
  - 硬件历史 HardwareHistory.json 默认仅保留最近 7 天，
    保留期 / 采样间隔 / 落盘间隔均可在「设置 → 系统」的历史趋势记录卡片中调整，
    过期数据会在每次启动时自动裁剪。
    程序保存前会把上一份数据轮转为 .bak，需要找回旧数据请看这里。

* 本地发布方式
  - 固定发布目录: C:\LiteMonitor
  - 一键部署: 双击仓库根目录的 deploy-to-LiteMonitor.bat
    该脚本先 publish 到暂存目录、再挑选性地复制文件，
    因此 settings.json 与各类历史记录不会被升级过程覆盖丢失。

* 本地安全加固（Web 服务，相对官方版）
  - 默认仅监听本地回环(127.0.0.1)，不再默认绑定全网卡(0.0.0.0)。
    官方版开启 Web 服务后整个局域网都能直接看到全部硬件数据，
    本定制版默认只有本机可访问，避免误开导致信息裸奔。
  - 新增开关 WebServerAllowLan（默认 false）：
    如需在手机/其他设备浏览器访问，请在 settings.json 中设
    "WebServerAllowLan": true，但务必同时设置 WebServerPassword
    （局域网模式下空口令将被拒绝启动，强制要求密码）。
  - 移除了全局 CORS 头(Access-Control-Allow-Origin: *)，
    Web 面板同源加载本就不需要跨域，此举可阻止任意恶意网页
    跨域读取你的硬件数据。
  - 口令校验加固：支持 Authorization 请求头、对 URL 编码口令做
    解码、采用恒定时间比较（防时序侧信道）。

* 本地功能调整与防御性加固（相对官方版）
  以下开关均位于「设置 → 系统」页，默认全部关闭（关闭时行为与官方版完全一致）。
  本版本已于 2026-10-15 在本机实机启动验证，功能正常。
  - 历史趋势记录（「历史趋势记录」卡片）：保留期（默认 7 天，可选 3/7/14/30/60/90 天）、
    采样间隔（默认 10 秒）、落盘间隔（默认 5 分钟）均可在设置中调整，不再写死。
  - 低功耗 / 省电模式（「性能与功耗」卡片）：「省电模式」与「电池供电时自动省电」开关，
    开启后刷新频率自动降低（最低 3 秒），减少常驻 CPU 唤醒与耗电。
  - 快速启动（「性能与功耗」卡片）：开启后跳过启动时的 3 秒 GPU 预热等待，
    CPU / 内存立即可见，GPU 数据稍后填充。
  - 省流量快速测速（「性能与功耗」卡片）：开启后下载 / 上传测速时长缩短约 2/3，
    流量消耗同步下降（测速为手动触发，本程序无后台自动测速）。
  - 硬件数据防御性加固：采集层新增异常值闸门（拦截 NaN/∞/非法负值，回退最后有效值或显示占位符）；
    监控项在未读到有效读数时显示「-」而非误导性的 0；硬件详情页对 NaN/∞ 同样显示「-」。

* 上游 PR 补充集成（相对官方版，2026-10-20）
  - 自定义传感器 ID（上游 PR #364）：当多块同型号硬盘 / 显卡导致自动匹配绑错传感器时，
    可点击监控项行内的齿轮⚙按钮，手动指定传感器 ID（如 /gpu-nvidia/0/power/0）强制绑定。
    留空则维持自动匹配，默认行为不变。
  - 全屏置顶守护（上游 PR #373）：开启置顶后，程序每 3 秒检测一次置顶状态，
    被全屏游戏 / VMware / 虚拟桌面切换夺走置顶时自动恢复；
    当本程序其他窗口（如设置面板）处于激活状态时自动跳过，不会强行抢置顶。
    本项默认生效（无需开关），与启动时的强制置顶刷新形成双保险。
